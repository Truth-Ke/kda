# Wayfinder Tracker

Use this directory for decision maps and tickets, following the vendored
`wayfinder` skill and its `TRACKER.md`.

```text
docs/wayfinder/
  map.md
  tickets/
    01-<slug>.md
```

Decisions are recorded in `map.md`; each ticket holds its own question,
resolution, and links to evidence. Do not use an external issue tracker.
